# Profe

App personal (PWA) para practicar inglés: lecciones adaptativas, Speaking con tutor por voz, quizzes, examen semanal y progreso.

- App: https://alfredovillau.github.io/profe/
- Código fuente: carpeta [`codigo/`](codigo/) (React + TypeScript + Tailwind, Vite). Para regenerar la app: `cd codigo && npm install && npm run build` y copiar `codigo/dist/` a la raíz.
